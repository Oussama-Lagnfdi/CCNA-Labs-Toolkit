# OSI Model

## Layer 7 - Application
User interface (HTTP, FTP, SMTP)

## Layer 6 - Presentation
Encryption, formatting

## Layer 5 - Session
Session management

## Layer 4 - Transport
TCP / UDP

## Layer 3 - Network
IP addressing, routing

## Layer 2 - Data Link
MAC address, switching

## Layer 1 - Physical
Cables, signals
